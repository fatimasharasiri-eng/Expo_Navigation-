# EXORA – Expo Navigation

Run (from this folder):
    python -m pip install -r requirements.txt
    python -m streamlit run streamapp.py

- `streamapp.py` + `ui_text.py` + `exora.css` = the whole app (design + all pages).
- `classes/` and `data/` = your original files, unchanged.
- `old_version/` = your previous multipage files (app.py, pages/, functions/, style.css), kept only as backup.
- Chatbot needs Ollama running with the llama3.2 model.
